# h4_oxidine / H4_Oxidine (The Sentient Conduit)

## What it is
The ultimate node-wire declutter tool. An "omniproxy" that bundles all your node connections into a single cable acting as a universal context pipeline, capable of intelligently unrolling properties. 

*For a highly technical structural breakdown, see the `OXIDINE-BREAKDOWN.md` documentation in the root path.*

## Expanded Description
Normally, a `KSampler` demands five separate, specifically-typed connection wires (Model, Positive, Negative, Latent, etc.) stretching across the screen, turning any sufficiently advanced workflow into a completely illegible plate of colored spaghetti. 

The `H4_Oxidine` solves this. You plug all your required parameters into this single proxy node. You are then provided a single "omniproxy" wire. You drag this single solitary wire across your canvas and plug it directly into every single socket of your target `KSampler`. When the `KSampler` activates and asks the wire for the "Model," the proxy shape-shifts and hands it the model object automatically. When the `KVae` asks the same wire for a "Vae", the proxy shape-shifts and hands it the Vae. 

## Key Technical Functionality
- **Sovereign Proxy Routing:** Operates by intercepting and redirecting Python's fundamental internal data-request protocols (`__getattr__`, `__getitem__`). It overrides native dictionary representations entirely.
- **Graph Optimization:** Completely collapses execution topology diagrams by allowing a massive section of graph instructions to funnel through one coherent lane structure.

## Use Case Scenarios
**Scenario 1: Complex Multi-Pass Inpainting**
Your workflow has an Upscaler node, a Base Generation node, a Detailer node, and a Final Composite node. Each of these nodes needs to access the core Base Model, VAE, and shared ControlNet text prompts. The standard method forces you to wire 15 individual overlapping strings from your primary loader across the screen to each processor. Using Oxidine, the process connects all variables to one node, and one line snakes gracefully to the different sectors, immediately cleaning the user interface and preventing connection loss errors.

## Examples
- **Basic Omniproxy Execution**:
  1. Drop an `H4_Oxidine` near your loaders.
  2. Wire `MODEL`, `VAE`, `CLIP`, `CONDITIONING (Positive & Negative)`, and `LATENT` directly into Oxidine.
  3. Drop a `KSampler` halfway across the canvas.
  4. Take the single output wire generated by `H4_Oxidine` and plug it manually into every input socket on the `KSampler`.
  5. The execution functions perfectly. You just saved five separate crossing wires.
